# Yard Card Jobs

Standalone installable web app (PWA) for a yard card business: bookings, crew texts, and an editable sign inventory.

- Open `index.html` over HTTPS (Netlify, GitHub Pages) and use Add to Home Screen.
- Jobs and settings are saved in the browser on each device.
- Sign inventory: Business tab. Enter totals owned; checking a sign on a job takes that many off the on-hand count until the job is marked complete.
